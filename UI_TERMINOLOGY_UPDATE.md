# UI Terminology Update

The product-facing checkpoint outcome labels are:

- **Cleared**: Green / `DetectedAndCounted`.
- **Undetected**: Yellow / `CountedNotDetected`.
- **Uncounted**: Red / `NotCountedNotDetected`.

The active distribution is **95-99% Cleared**, **0-4% Undetected**, and **1% fixed Uncounted**. Purple operators target only Undetected/Yellow pedestrians; Uncounted/Red pedestrians continue toward the exit without operator intervention. Cyan remains reserved for the optional Dasher incident.
