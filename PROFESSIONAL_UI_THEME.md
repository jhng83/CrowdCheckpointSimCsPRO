# Professional UI Theme

This visual-only update moves the application from a research-prototype palette toward a professional operations-console presentation.

## Product chrome

- Deep navy application background: `#0B1220`
- Dark slate sidebar: `#111827`
- Elevated dashboard cards: `#172033`
- Subtle borders: `#293548`
- Primary text: `#F3F4F6`
- Secondary text: `#9CA3AF`
- Interaction accent: `#3B82F6`

## Operational semantic colours

- Cleared: green `#22C55E`
- Undetected: amber `#F59E0B`
- Operator: violet `#8B5CF6`
- Dasher: cyan `#22D3EE`
- Unclassified/queue passenger: neutral off-white `#D5D8DC`

## UX changes

- Primary actions use blue rather than every button competing for attention.
- Pause uses restrained amber; Exit uses restrained red.
- Dashboard sections use elevated cards with accent headers.
- Detection labels use semantic colour while numeric values remain high-contrast neutral text.
- Operator capacity bars are shorter and use green/amber/red only as status information.
- In-world operator capacity bars are also shorter with a neutral track.
- Environment colours are darker/slate so people and status information remain the visual focus.

## Simulation guardrail

This update is presentation-only. It does not change SFM, queue motion, detection quotas, operator acquisition, manual clearance, fatigue logic, Dasher state logic, exact-two-catcher behaviour, right-of-way rules, timing, or world-space collision dimensions.
