# Dasher Clearance Time Control

- Adds a pre-simulation **Dasher clearance time** slider from **10 to 30 seconds**.
- The value controls how long a secured Cyan/Dasher remains at the holding point before it is removed and the incident is cleared.
- Default remains **10 seconds**, preserving the previous baseline behaviour.
- The value is saved and restored with scenario configuration JSON files.
- Existing Dasher pursuit, catch distance, two-catcher requirement, group stop, escort speed, and holding-point location are unchanged.
