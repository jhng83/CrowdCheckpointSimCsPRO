# Three-outcome checkpoint model restored

The active checkpoint outcome model is now:

- **Cleared (Green): 95% to 99%**, derived automatically.
- **Undetected (Yellow): 0% to 4%**, user-adjustable before the run.
- **Uncounted (Red): fixed at 1%**.

The default remains **95% Green / 4% Yellow / 1% Red**. Red pedestrians continue toward the exit and are intentionally ignored by Purple operators. Cyan Dasher incidents remain a separate incident class and do not consume normal checkpoint outcome quota.
